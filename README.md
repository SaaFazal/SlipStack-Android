# SlipStack

Full-stack Android mobile app utilising ML Kit and regex patterns for on-device receipt scanning. SlipStack helps users effortlessly digitise and track their physical receipts and spending.

## Features
- **On-Device OCR:** Fast and private receipt scanning utilising Google ML Kit.
- **Offline-First Architecture:** Works seamlessly without an internet connection, featuring background sync.
- **Dynamic Data Extraction:** Automated extraction and categorisation of line items using robust Regex patterns.
- **Interactive Data Visualisation:** Visualise spending habits with interactive charts (MPAndroidChart).
- **Automated Categorisation:** Smart grouping and analysis of extracted purchase data.

## Tech Stack
- **Platform:** Android (Java)
- **Machine Learning:** Google ML Kit
- **Local Database:** Room / SQLite
- **Visualisation:** MPAndroidChart
